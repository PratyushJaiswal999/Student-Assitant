# Study Assistant

Paste your notes or a topic, pick Flashcards or Quiz, and get an interactive study tool generated by AI. Take the quiz, get scored, and retest just the questions you got wrong.

This is not a chatbot — the AI returns structured JSON, which the app parses into flashcards or a quiz you can actually interact with.

## Setup

**Requirements:** Node.js 18+, an API key from your chosen AI provider (this project uses Groq's free tier — swap the provider in `backend/prompt.js` and `backend/server.js` if you use something else).

```bash
# 1. Clone and enter the repo
git clone <your-repo-url>
cd study-assistant

# 2. Backend
cd backend
npm install
cp .env.example .env   # add your API key to .env
npm run dev             # starts on http://localhost:3001

# 3. Frontend (new terminal)
cd frontend
npm install
npm run dev              # starts on http://localhost:5173
```

The frontend is set up to call the backend at `http://localhost:3001/api/generate` — update `src/api.js` if you change the port.

## Usage

1. Paste notes or type a topic into the text box.
2. Choose "Flashcards" or "Quiz".
3. Click Generate and wait a few seconds.
4. Flashcards: click a card to flip it, use Next/Prev to move through the deck.
5. Quiz: answer each question, see your score at the end, and click "Retest wrong answers" to try only the ones you missed.
6. If generation fails or the response is unusable, you'll see an error message with a Retry button.
